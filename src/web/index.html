Bahnrennen

Wie das Pferderennen auf der Kirmes: 4 Bahnen, 12 Felder, wer zuerst im Ziel ist, gewinnt. Setzt auf eine Nummer! Ein Rennen dauert etwa eine halbe Minute, danach zeigt die Tafel wieder die Abfahrten.

Promos

Kleine Nachrichten vom Café in der 4. Zeile. Auf eine Promo tippen, um sie zu bearbeiten.
Promos sind gerade aus (unter „4. Zeile“ einschalten).

Icons

Symbole für die Promos. Eigene lassen sich ändern.
Punkte anklicken oder darüber wischen (12 × 9).

Technik WLAN, Log, Neustart

Abfahrts-Animation

Wie oft eine abfahrende Bahn bzw. ein Bus aus der Zeile fährt. 1 = jedes Mal, 0 = nie. Gilt nach „Änderungen speichern“.

WLAN

Verbunden mit ?. Nach dem Speichern startet die Tafel neu. Klappt die Verbindung nicht (z. B. Tippfehler), nimmt sie nach etwa einer Minute wieder das bisherige WLAN.

Log

Die letzten Meldungen der Tafel, dieselben wie am USB-Anschluss. Wird laufend ergänzt, solange es angezeigt wird.



Neustart


Startet die Tafel neu, die Seite lädt danach von selbst neu.

 





Die Einstellungen wurden inzwischen auf einem anderen Gerät geändert.
